# Демонстрационный сценарий

Дата актуализации: `2026-05-24`

## 1. Назначение документа

Документ фиксирует, как демонстрировать завершённый `MVP 1` без смешивания текущих возможностей и будущих задач `MVP 2`.

## 2. Что именно показывается

На demo показывается завершённый сценарий `MVP 1`:

1. вход
2. организация
3. загрузка документов
4. обработка
5. поиск по фрагментам
6. анализ отчёта
7. требования / XAI / риски / матрица
8. генерация
9. export
10. согласование

## 3. Demo dataset

Базовый dataset для MVP 1:

- `rosobrnadzor_sample.txt`
- `rosobrnadzor_evidence_site.txt`
- `organization_profile.json`
- `education_metrics.csv`

Рекомендуемые категории:

- нормативный документ
- доказательный документ
- другое
- таблица данных

## 4. Ручной demo-сценарий

1. Открыть `http://localhost:5173`.
2. Войти под тестовым пользователем.
3. Создать или выбрать организацию.
4. Перейти в `Документы`.
5. Загрузить demo dataset.
6. Обработать документы.
7. Выполнить поисковый запрос по фрагментам.
8. Перейти в `Отчёты`.
9. Создать новый отчёт.
10. Включить документы в отчёт.
11. Нажать `Анализ`.
12. Проверить:
    - `Требования`
    - `Матрицу`
    - `Объяснения`
    - `Риски`
13. Выполнить одну ручную корректировку требования или review-действие.
14. Нажать `Генерация`.
15. Открыть `Редактор отчёта`.
16. Выгрузить `DOCX`, `XLSX`, `ZIP`, `HTML`.
17. Отправить отчёт на согласование.
18. Проверить `Уведомления` и `Аудит`.

## 5. Где смотреть результат

- `Документы` — обработка и поиск
- `Требования` — выделенные требования
- `Матрица` — карта доказательств
- `Объяснения` — XAI-логика
- `Риски` — открытые пробелы и рекомендованные действия
- `Редактор отчёта` — сгенерированные разделы
- `Уведомления` и `Аудит` — трассы review-контура

## 6. Что именно подтверждает этот demo

Demo подтверждает, что `MVP 1` завершён как функциональное ядро:

- web flow работает
- документный pipeline работает
- аналитика работает end-to-end
- пользователь видит XAI
- export работает
- базовый контур согласования работает

## 7. Что не нужно смешивать с demo `MVP 1`

В этот demo не нужно искусственно включать как будто уже завершённые функции:

- advanced multimodal vision
- large real-corpus evaluation
- электронная подпись
- external integrations
- iOS client

## 8. Что станет demo-фокусом `MVP 2`

Когда начнётся `MVP 2`, demo будет расширяться в сторону:

- OCR / vision quality
- расширенные кейсы `real_corpus`
- более сильный evidence linking
- более качественные разделы

## 10. Короткий итог

Этот сценарий предназначен именно для демонстрации завершённого `MVP 1`.  
Будущие версии должны расширять demo, а не подменять им текущую завершённую поставку.
