# Варианты графического логотипа EX.AI

Документ фиксирует рабочие варианты логотипа для EvidenceXAI. Пока ни один из них не переносится в production UI автоматически: текущая правка только убирает белую подложку под текстовым `EX.ai` в sidebar.

## Вариант 1. Signal Wordmark

Файл: `frontend/src/assets/logos/exai-logo-01-signal.svg`

Идея: AI-сигнал, связка доказательств и компактный SaaS-лейбл. Самый яркий вариант для web-интерфейса, login-экрана и презентационных материалов.

Рекомендация: использовать как основной production-логотип, если хотим более технологичный и заметный образ.

## Вариант 2. Evidence Seal

Файл: `frontend/src/assets/logos/exai-logo-02-evidence-seal.svg`

Идея: проверка, доказательность, контроль и доверие. Визуально ближе к enterprise/gov-tech, хорошо подходит для дипломной темы и государственных сценариев.

Рекомендация: использовать, если хотим сделать акцент не на AI-стартапе, а на надежной проверочной системе.

## Вариант 3. Neural Frame

Файл: `frontend/src/assets/logos/exai-logo-03-neural-frame.svg`

Идея: документ, нейронный контур и объяснимый переход от evidence к выводу. Самый спокойный и инженерный вариант.

Рекомендация: использовать для технической документации, README и внутренних страниц, но для sidebar он может быть визуально сложнее первых двух.

## Предварительный выбор

Для production-интерфейса я бы выбрал `Signal Wordmark`: он лучше читается в малом размере и сильнее поддерживает бренд `EX.AI`. Для дипломной защиты можно дополнительно использовать `Evidence Seal` на титульных материалах, потому что он лучше передает идею проверки и доверия.
